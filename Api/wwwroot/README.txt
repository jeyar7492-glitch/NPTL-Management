NPTEL Management PWA

This web app is served by the ASP.NET Core API from /wwwroot.
Open / in a browser to use the portal.
Install from Chrome using the browser install prompt/menu when available.

The app uses the existing API endpoints:
- /api/v1/auth/student/login
- /api/v1/auth/staff/login
- /api/v1/auth/admin/login
- /api/v1/student/*
- /api/v1/staff/*
- /api/v1/admin/*
